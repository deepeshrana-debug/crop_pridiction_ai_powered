# crop_pridiction_ai_powered

I built this project to help farmers get a data-backed idea of which crops might yield well, instead of relying purely on guesswork or tradition. It takes in relevant inputs and uses a machine learning model to predict crop yield, then shows the results in a simple, visual way through charts — so the numbers actually make sense at a glance.

Why I built it: Agriculture is still one of the biggest sectors where technology hasn't fully caught up, and I wanted to explore how something as accessible as a web app could actually help with real decisions on the ground.

What it does:

Takes input data and runs it through a trained ML model to predict crop yield
Displays results using Chart.js so trends and predictions are easy to understand
Built as a REST API with Flask, so it's easy to extend or plug into other apps later

Tech stack: Python, Flask, REST API, Chart.js

What I learned: This was my first time connecting a machine learning model to a working web app end-to-end — from building the backend logic to actually visualizing the output in a way a non-technical person could understand.
